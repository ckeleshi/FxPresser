Release文件说明:

fxpresser_patch.zip    --> 解禁魔手的补丁，如果你在使用任何一款外置魔手，那就需要这个

external_fxpresser.zip --> 我的外置魔手，需要配合fxpresser_patch

internal_fxpresser.zip --> 我的内置魔手，功能最全，无需fxpresser_patch

***请使用OpenGL图形模式，否则什么东西都不会生效***

FFO启动时会删除opengl32.dll，所以你需要禁止qqffo.exe删除opengl32.dll，任意一款安全软件都应该有这种功能。或者修改opengl32.dll的文件安全选项，禁用删除权限
